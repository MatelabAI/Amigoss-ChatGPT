# Amigoss ChatGPT

A static preview of the approved Amigoss homepage redesign concept. It presents the new editorial direction, original Amigoss wordmark and typefaces, six membership benefits, and the subtle map connecting Latin America with Sydney.

## Preview

Open `index.html` in a browser or serve this folder with any static file server. The layout is responsive. The `Events` link opens Amigoss on Facebook, `Contact` opens an email, and `Join Amigoss` opens the existing membership form at [amigoss.org/join-us](https://amigoss.org/join-us/).

## Scope

This repository contains the homepage concept only. It is a design preview, not the complete redesigned website or a production release. The membership form remains on the existing Amigoss site; this preview has no embedded form, payment gateway, analytics, or Facebook widget. Membership is shown as AUD $15 per year, payable by bank deposit or in person.

The map is an illustrative connection, not travel routes or member-location data. The community artwork is an illustration, not a photograph of actual members.

## Files

- `index.html` — responsive concept page.
- `css/` — shared site styles and concept-specific styles.
- `img/` — Amigoss wordmark, community illustration, and vector map.
- `fonts/` — Architects Daughter and Roboto.
- `js/site.js` — accessible mobile navigation.
